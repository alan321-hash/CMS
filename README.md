# CMS — Servicios Audiovisuales, Marketing Digital y Desarrollo Web

## 📌 Descripción del proyecto

CMS es un sitio web diseñado para presentar servicios audiovisuales, marketing digital y desarrollo web. Su identidad visual es moderna, profesional, minimalista y utiliza una estética basada en blanco y negro.

## 🚀 Funcionalidades

- Presentación de la empresa y sus servicios.
- Galería de trabajos y contenido audiovisual.
- Acceso a redes sociales y contacto por WhatsApp.
- Inicio de sesión con Google mediante Firebase Authentication.
- Registro y almacenamiento de usuarios en Firebase Firestore.
- Modificación de datos de usuarios.
- Baja lógica de usuarios mediante un campo de estado.
- Diseño adaptable y navegación con efectos visuales.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura del sitio web.
- **CSS3:** estilos, diseño y animaciones.
- **JavaScript:** interactividad y lógica del sitio.
- **Firebase Authentication:** autenticación con Google.
- **Firebase Firestore:** almacenamiento y gestión de usuarios.
- **Git y GitHub:** control de versiones y alojamiento del código.
- **MkDocs:** documentación del proyecto.

## 🔐 Autenticación y base de datos

El sistema utiliza Google para iniciar sesión. Los datos de los usuarios se almacenan en Firebase Firestore. También permite modificar el nombre de un usuario y realizar una baja lógica, cambiando su estado sin eliminar físicamente el registro.
